# 澳门词元中心（拟议）· AI 产业交易仿真

> "澳广州数交所澳门词元交易中心 / 澳门词元中心"是**拟议名称**：尚未登记，不是广州数据交易所的分支机构，未取得其品牌授权，也没有任何金融或交易场所牌照。本项目是按方案文档搭出来的前端仿真环境。

## 项目概述
- **名称**：澳门词元中心（拟议）· 仿真站（代码名 webapp，站点版本 4.1.1）
- **依据**：《全球AI产业交易与Web3／Web4升级方案 V4.0》（2026-11-19）G01—G26 主方案；行情部分沿用此前的《战略深化方案 V2.0》
- **目标**：把"算力与模型服务 → AI 影视与企业任务 → 合法授权 → 真实回款 → 合同分配"这条产业链做成可以亲手操作的演示，让每条业务规则都能被点出来、被拦下来、被复算
- **语言**：中文 / English，顶栏右上角切换（英文为本站自行翻译，见下文"中英文切换"）
- **定位**：产品概念演示。模型、服务商与报价是真实公开数据；成交、盘口、走势是合成数据；挂牌、许可、权益、分账是示例数据。界面逐处标注

## 业务规则（均有单元测试）
**挂牌与许可**（G04、G11—G13）
- 挂牌卡必填项不齐、授权过期、第三方权利未核清、名称含误导措辞、金融化对象，都进不了挂牌
- 三道审核：主体及地域 → 资产及权利 → 产品及履约；退回必须写理由
- 排他范围按 地域 × 语言 × 渠道 × 期限 判定相交，同一标的的相交排他授权被阻断
- 锁定时对权利范围、价格、费率、挂牌版本算快照哈希；签约前任何一项被改动都签不了
- 中心不代收代管：只登记外部到账凭证引用，未到账不能交付
- 已准入的挂牌改动后版本号 +1，重新走审核
- 中心收入只确认服务费（示例费率 8%），不把合同对价当自有收入

**算力权益**（G20）
- 守恒式：容量 = 未售 + 已用 + 可用 + 冻结 + 到期 + 退款，每步都检查
- 超卖阻断；同一回执重复提交不重复计量
- 转让先冻结，供方同意且受让方确认才生成后继权益；转让不创造容量
- G20 算例可逐步重放：1,000 → 已用 820 + A 余 100 + B 余 80

**版税分账**（G19）
- 整数分计算，最大余数法，各项相加严格等于毛收入
- 没有凭证引用的扣项不进瀑布；分配比例之和必须为 100%；费用只扣一次
- 未到账时可支付金额为 0，不显示"已分配"

**受控 Agent**（G18）
- 只读自动放行；预算、地域、已批准供方范围内的低风险调用按事前授权执行
- 新增供方、地域变化、排他授权、权益转让、法币付款、权限升级须人工审批
- Agent 不能自我审批；金融投资与借贷一律拒绝
- 上下文文字（含提示注入）不参与裁决，审计只留摘要

**跨法域**（G07、G16）：只输出"有条件"或"关闭"，从不输出"合规通过"。稳定币结算、面向公众的收益份额路径关闭

**财务模型**（G21—G22）：税前、融资前。三种情景与方案公布值的最大偏差 0.0049 / 0.0047 / 0.0042 万美元；恒等式 累计现金 + 期末应收 + 固定资产净额 = 累计税前利润 成立。金融层收入为 0

**行情**（V2.0 §06—§11）：固定篮子 = 80% 输入 + 20% 输出；无样本留空不复制前收；发布门槛 ≥3 家独立供应主体、≥5 个独立买方、≥10 笔样本；指数固定基期 100、等品牌组权重

**入场**：未入场不能下单、签约、提交挂牌或询价。内地主体校验统一社会信用代码校验位；澳门、香港及其他地区只要求填写登记编号，不校验格式

## 稳定性与交互
- 页面加载失败、视图渲染出错、未知路径各有独立的状态面板和重试入口，不会白屏
- 启动时目录加载失败自动重试 3 次；上游不可达回退离线快照并显示快照时间
- 单个视图的刷新连续出错 3 次会暂停并提示，不影响其他页面；标签页隐藏时暂停刷新
- 本机存储损坏或版本不符时重置为初始状态，原文备份到 `<键名>.corrupt`；写入失败退回内存继续可用；页脚显示存储与网络状态
- 多标签页同时打开时，数据变更有提示
- 危险操作（清空、撤销、撤牌、退回）用站内对话框确认，必填理由不填不能提交
- 响应头：CSP（脚本只允许同源）、`nosniff`、`Referrer-Policy`、`Permissions-Policy`
- 中英文在 1440 / 1100 / 390px 三档宽度下 20 个路由均无横向溢出；中等宽度下顶栏逐级收起时钟、快捷键提示等次要信息，语言开关始终保留

## 中英文切换
- **入口**：顶栏右上角"中文 / EN"；也可以直接用链接 `/?lang=en` 或 `/?lang=zh`。选择写入 Cookie `lang` 与本机存储 `zjt.lang`，下次打开沿用；切换时整页重新加载
- **填到一半的表单**：切换前本页改动过的输入项会在重载后填回去，并提示"已保留"；没动过的默认值跟随新语言。记录只放在本标签页的 sessionStorage，用一次即删、两分钟内有效，不进本机长期存储，也不进存证链。三种情况不带过去：交易页的委托价格与数量（重载后默认品种可能不同）；版税分账页增删过行之后各行里的内容（行号对不上，宁可不填也不填错行，此时会明确提示有几项没恢复）；密码、文件、隐藏域
- **做法**：中文是唯一的源文本。英文只在显示时翻译——`$t("中文原文 {0}", 参数)` 按中文原文查词典；规则模块返回的已拼好的中文由 `tx()` 整句、按模板、按分隔符三级匹配；最后有一层兜底，凡进入页面的中文文本和提示属性都再过一遍。外壳（顶栏、导航、页脚）由服务端按语言直接渲染，`<html lang>` 随之变化
- **不随语言变化的部分**：规则模块（`core/`）、本机存储的数据、存证链里的操作方名称始终是中文，所以同一份数据在两种语言下哈希一致，切换语言不会让存证链校验失败
- **不翻译的部分**：使用者自己填写的内容（机构名、挂牌标题、理由等）、模型与服务商的原始名称、`SIM-` 编号
- **数字**：中文用"万 / 亿"，英文用 K / M / B；图表时间轴按语言本地化
- **搜索**：Ctrl / ⌘ + K 的搜索在英文界面下同时匹配中文原文和英文译文
- **禁用宣传语**：挂牌审核的禁用词同时检查中文和对应英文（如 guaranteed authentic、capital guaranteed）
- **翻译的性质**：约 2,530 条英文词条是本站自行翻译，没有经过专业译审。"Macau Token Centre (proposed)"以及文中出现的机构、文件、制度名称的英文写法，都是本站的非官方译法，不代表相关机构的官方英文名称
- **文件**：`public/static/js/i18n.js`（引擎）、`public/static/js/i18n/en.js`（主词典）、`public/static/js/i18n/en-shell.js`（外壳词典，服务端与浏览器共用）、`public/static/js/formkeep.js`（切换语言时保留表单）、`scripts/i18n-check.mjs`（完整性检查）

## 使用说明
1. 打开"总览"，按"上手路径"走，大约十分钟
2. "可信治理 › 入场审批"：填入演示数据 → 提交 → 逐环节通过。未入场只能看，不能办
3. "产业交易 › 挂牌大厅"：打开一个挂牌中的商品发询价，然后依次报价、锁定、签约、登记到账、交付、验收；中途可点"试试静默改价"
4. "算力权益"：先点"重放算例"看 G20，再自己登记批次、预订、核销、转让
5. "版税分账"：改毛收入、扣项、比例，看瀑布怎么变
6. "溯源存证"：封存批次，给任意一条记录出具证明，再试篡改和伪造
7. "受控 Agent"：签发一张凭证，依次点九个场景
8. "研究 › 财务模型"：切换情景，拖动滑块
